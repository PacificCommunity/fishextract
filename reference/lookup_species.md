# Look up the species names given the species codes

Look up the species names given the species codes

## Usage

``` r
lookup_species(species = NULL, refresh = FALSE)
```

## Arguments

- species:

  Optional character vector of species codes to filter by. If `NULL`,
  all species are returned.

- refresh:

  Logical. Force a re-query of the database and refresh the cache.
  Defaults to `FALSE`.
