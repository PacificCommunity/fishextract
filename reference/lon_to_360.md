# Convert decimal longitude (-180 to 180) to 0-360 for Pacific-centred maps

Convert decimal longitude (-180 to 180) to 0-360 for Pacific-centred
maps

## Usage

``` r
lon_to_360(lon)
```

## Arguments

- lon:

  Numeric vector of longitudes in -180 to 180 format.

## Value

Numeric vector of longitudes in 0-360 format.
