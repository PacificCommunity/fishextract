# Look up the weight measurement codes

Look up the weight measurement codes

## Usage

``` r
lookup_weight_codes(weight_code = NULL, refresh = FALSE)
```

## Arguments

- weight_code:

  Optional character vector of weight codes to filter by. If `NULL`, all
  weight codes are returned.

- refresh:

  Logical. Force a re-query of the database and refresh the cache.
  Defaults to `FALSE`.
