# Look up the length measurement codes

Look up the length measurement codes

## Usage

``` r
lookup_length_codes(length_code = NULL, refresh = FALSE)
```

## Arguments

- length_code:

  Optional character vector of length codes to filter by. If `NULL`, all
  length codes are returned.

- refresh:

  Logical. Force a re-query of the database and refresh the cache.
  Defaults to `FALSE`.
